**Студент:** Дейнекин Эльдар
**Вариант 10:** страна — Швейцария, узор — `j`, функция — `y = x / 3`,
условие — числа от −3 до 3 и остальные.

## Что сделано

| № | Задание | Реализация |
|---|---------|------------|
| 1 | Флаг страны | `flag()` — матрица 16×16, красный фон + белый крест, вывод цветом через escape-последовательности |
| 2 | Повторяющийся узор | `pattern()` — элемент «j» (два кольца) строится по уравнению окружности `ring_tile()`, плитка повторяется 2×2 |
| 3 | Анимация из 3–4 кадров | `animation()` — 4 кадра «пульсирующего» креста, `os.system("cls")` + возврат курсора `ESC[H` и очистка строк `ESC[K` |
| 4 | Диаграмма процентного соотношения | `diagram()` — по `sequence.txt`: числа в диапазоне [−3; 3] и все остальные, сумма = 100 % |
| 5 | Допзадание: график функции | `graph()` — первая четверть `y = x / 3`, буфер 9×41, точки наносятся на сетку, оси рисуются отдельно |

Изображения **генерируются** в двумерном буфере и выводятся escape-последовательностями,
а не печатаются заранее подобранными строками.

## Запуск

```bash
python main.py            # все пункты подряд
python main.py flag       # только флаг
python main.py pattern    # только узор
python main.py anim       # только анимация
python main.py diagram    # только диаграмма
python main.py graph      # только график (допзадание)
```

Требуется Python 3.9+ (используются аннотации типов вида `list[list[str]]`).
На Windows 10+ обработка ANSI включается автоматически функцией `enable_ansi()`.
